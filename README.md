# Лабораторная работа №3. Вёрстка макета с помощью Flexbox и Grid
Выполнил Прикуль Александр Группа 932404

## Описание проекта
Данный проект является продолжением Лабораторной работы №2 и посвящён освоению современных методов CSS-вёрстки: Flexbox для одномерных макетов, CSS Grid для двумерных, а также принципам адаптивной вёрстки с использованием медиа-запросов

## Выбранный вариант
Вариант 5. Тема «Геймер и разработчик игр»

## Использованные технологии
Использовал современные возможности CSS3, выполнил все требования методички, соблюдая критерии задания. Были использованы:
* HTML5 
* CSS3 

## Реализованные требования:

1. **Flex-карточки:**
   * Навигационное меню
   * Карточки «Любимые жанры игр»
   * Использование `<article>` для семантически верного оформления карточек

2. **Grid-дашборд:**
   * Дашборд «Статистика игрового времени»
   * Использование `<section>` для семантического оформления дашборда

3. **Адаптивная вёрстка:**
   * Десктоп: карточки жанров в 4 колонки, дашборд в 3 колонки
   * Планшет (`max-width: 1024px`): карточки жанров в 2 колонки, дашборд остаётся в 3 колонках
   * Мобильный (`max-width: 767px`): карточки жанров в 1 колонку, дашборд по 1 в строку
   * Отсутствие горизонтальной прокрутки на всех устройствах
